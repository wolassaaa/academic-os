# 夜间交互参考：P0/P1 后复核

日期：2026-10-17（Asia/Taipei）。只采纳适合轻量个人学业看板的部分，不复制整套产品。

## 已查阅的官方说明

- [Sunsama Gmail Integration](https://help.sunsama.com/docs/integrations/gmail/)：邮件浏览/筛选与导入任务分开，任务保留邮件上下文并可返回邮件。适配到本项目：原文与正式事项双向跳转，返回保留筛选；候选不因被阅读自动成为正式任务。其归档/标记等邮箱自动操作本轮不采纳。
- [Todoist filters](https://www.todoist.com/help/todoist/features/introduction-to-filters-V98wIH)：可组合日期、项目等条件筛选，并明确无日期的查询。适配判断：本项目用可见的组合控件而非新查询语言，明确“收件日期”与任务DDL不同；无结果提供一键清除筛选。这是针对本项目的设计推导，不声称复制其具体控件。

## 本轮实际落点

1. 邮件 → 正式事项 → 原邮件双向跳转，嵌套返回地址只允许同源邮件详情且邮件键匹配。
2. 全文与摘要分层，长原文使用原生折叠控件，截断明确提示；候选逐条显示，原文只作为资料。
3. 搜索、日期、账号和核对条件可组合且随返回保留；修改日期自动选择自定义范围；无结果直接清除筛选。
4. 不照搬邮箱写入自动化、复杂过滤DSL或第三方集成扩张，继续保持现有底座与Material外观。
