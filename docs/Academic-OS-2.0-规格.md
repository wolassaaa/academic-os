# Academic OS 2.0 产品与工程规格

状态：用户批准实施；2026-10-12。模型分析明确关闭，只保留接口和接入规格。

## 产品边界
单个常开 Windows 后台；浏览器工作台与只读远程看板；Agent 通过版本化 API / MCP 共用核心。SQLite 保存事实，Markdown 是派生摘要。Moodle 永远只读。Google 是可编辑的外部日历，Apple 通过 Google 账号编辑；飞书为单向镜像。飞书与邮件用于通知。首版不接 iCloud、Outlook，不引入自动语义推断。

## 行为约束
- 来源截止、固定活动、执行时段必须分开；未知时间不可生成日期占位。
- 邮件保留原文与多个日期节点；规则无法判断语义时标记 needs_analysis。不得把所有日期都自动作为日程发布。
- 每个事项和计划均有稳定 ID、版本、证据、历史；外部手动调整读回；并发修改产生冲突；用户删除后不能擅自重建。
- 修改通过草稿、确认、持久化作业执行；请求使用幂等键。确认是用户操作，Agent 凭证默认不含确认权限。
- 通知状态区分 queued / sending / delivered / failed / acknowledged / completed / snoozed；delivered 只代表渠道接收。失败重试，崩溃后回收租约；不承诺渠道的 exactly-once。
- 影子模式默认开启：禁止任何日历远端写入和通知发送，但允许读取与生成预览；需显式 cutover 才进入 live。
- 不执行旧业务脚本。Moodle 独立子进程使用经过复制的只读采集模块，网络环境单独隔离。
- 数据与凭证不入 Git 或常规迁移包；安装路径可变；备份使用 SQLite online backup。

## 访问
管理服务绑定 loopback，Agent 使用分权限 bearer token。远程独立端口只开放登录、登出与看板读取。密码使用 scrypt，服务端会话使用随机凭证、过期和撤销；设置 HttpOnly/SameSite cookie；生产 HTTPS 使用 Secure。登录限速。未初始化时无默认密码或匿名私人数据。

## 运行
服务内单一持久化 worker；数据库租约防止双实例。网络超时、独立代理、单作业时间预算、失败退避。看板每 30 秒刷新，展示心跳和每来源更新时间，失败不伪装健康。设备关机仍会使本节点不可用；单节点不是高可用集群。

## 交付验收
测试事项去重、多日期、未知时间、已交作业、计划冲突、幂等、权限、并发版本、日历分页/游标失效/删除/回环、飞书镜像、通知失败/租约、重启恢复、备份恢复和迁移脱敏。实际第二台设备、外部登录及真实渠道投递分别记录环境验证结果，不能用模拟测试代替。
