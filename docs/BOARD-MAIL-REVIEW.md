# 看板逐条邮件核对 v0.5

沿用本地会话和既有 `/api/v1/items/{id}/mail-review`，未增加后台表或新权限。

- 每条候选独立编辑标题和截止，确认进入正式事项并保留原 ID。忽略仅隐藏候选，恢复后仍待核对；混合来源和历史正式事项不出现候选修改表单。
- 截止输入使用浏览器时区（明确显示），未编辑的源 ISO 保持精度和原时刻。未知时间留空；夏令时不存在/重复时间不猜测，可填写带明确偏移的精确 ISO。精确输入优先，支持至 2089 年。
- 确认、忽略和恢复均显示确认对话框，默认焦点取消，Escape 取消；请求中禁止重复操作。日期证据与原邮件保留。
- 请求携带 CSRF、业务版本和幂等键；权限仍由服务判断。默认 Agent 无确认权限，远程看板不提供邮件原文或写路由。
- 网络中断/无可靠回执保留原请求和幂等键；核实未决操作重发完全相同的 payload。不会以新版本自动重放。未决操作和草稿仅在当前页面内存中保存；离开页面后以服务状态重新核对。
- 其他候选操作或刷新不覆盖当前草稿。服务器版本变更后草稿保留且禁止提交，需显式放弃草稿重新核对。关闭浏览器不会保存未提交草稿。
- 操作回执先应用，再刷新；刷新失败显示“操作已确认”，不会声称写入失败。已有更高版本时不回退到旧幂等回执。
- 确认不触发日历写入；未确认/忽略候选仍由既有正式查询与提醒门禁排除，邮件到达通知独立保留。

验证仅使用临时数据库、虚构邮件与本地临时 HTTP 服务；保留既有工作台作为冲突处理入口。业务可访问性与恢复能力优先，动效只使用既有本地 GSAP/AcademicMotion。
