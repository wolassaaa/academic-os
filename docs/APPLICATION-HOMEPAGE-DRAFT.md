# Academic OS 2.0

Academic OS 是供本人使用的 Windows 学业管理工具，集中查看学校邮件、课程作业、截止日期和日程安排。日常安排可以在 Google 日历及连接同一 Google 账号的 Apple 日历应用中查看。

## 功能

- 本人登录 Google 后，读取邮箱和本人选择的日历。
- 登录 HKBU Moodle 后，只读采集课程、作业、截止日期及可取得的提交状态。
- 手动维护事项，生成可核对的执行计划；确认后才执行日历写入。
- 记录同步状态、冲突与通知结果，提供本机管理页面和可选的独立登录只读看板。
- 为 Agent 保留独立权限接口及 Markdown 汇总。当前版本不启用模型分析。

## 数据与访问

程序后台运行在用户自己的 Windows 设备上。Google 与学校密码不交给本程序保存；离线授权由 Windows 凭据管理器保存，业务数据保存在该设备的 SQLite 数据库中。外部日历写入和通知默认处于预览状态，启用实际执行前需要用户确认。

Google 登录、邮件与日历 API、学校服务需要可用网络及本人授权。学校服务权限可能导致部分课程无法读取，程序明确显示不完整状态。
