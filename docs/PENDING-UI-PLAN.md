## 展示与标记

- 邮件使用固定的信封图标和“邮件”标记；作业、测验、考试和资料分别显示类型标记，不只依靠颜色区分。

## 筛选与课程链接

- 作业／资料页提供联动下拉：全部课程 → 当前课程的具体条目／链接。切换课程时重置条目选择。
- 同时提供类型、状态、标签、关键词和日期筛选；不同筛选条件共同生效，多选标签按“匹配任一所选标签”处理。
- 作业日期默认按真实截止时间筛选，可切换为学习安排时间；邮件按收件时间筛选。
- 日期支持全部、今天、未来七天、自定义范围和无日期。使用系统设置的时区，自定义结束日期包含当天；不为无日期资料虚构时间。
- 显示筛选结果数量、当前筛选条件及“一键清空”；刷新后保留筛选条件。
- Moodle 课程目录补充可访问的作业、测验、课件、阅读资料等入口，只同步名称、类型、课程、链接及学校提供的日期，不下载全部文件。
- 同一个 Moodle 活动与已有作业关联展示，避免重复出现；只有资料链接的条目不自动加入排程或提醒。
