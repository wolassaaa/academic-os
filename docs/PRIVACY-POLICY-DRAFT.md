# Academic OS 隐私声明

更新日期：2026-10-12

Academic OS 是在用户本人 Windows 设备上运行的学业管理工具。本声明说明当前关闭模型分析的版本如何访问和使用数据。

## 访问哪些数据

经用户亲自授权，程序访问 Google 邮件元数据和正文、Google 日历列表和选定日历事件；学校登录成功后访问 Moodle 提供的课程、作业、截止日期与提交状态。程序保存用户手动维护的事项、执行计划、同步映射、通知结果和操作记录。访问范围受用户授权及学校实际开放的服务权限约束。

程序不保存 Google 或学校账号密码。程序使用 Windows 凭据管理器保存离线授权令牌；本地管理密码以加盐密码哈希保存。

## 用途

数据用于展示邮件依据、课程作业及截止日期，安排执行时间、发现冲突，执行用户确认的日历修改，以及向用户配置的渠道发送提醒。Google 日历写入仅针对系统管理的事件。学校数据接口只读。

Academic OS 对从 Google API 接收的信息的使用和转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。数据不用于广告、出售或训练通用模型。当前版本不启用模型分析，不将邮件或学校资料发送给模型提供方；将来启用新的数据处理功能前应更新声明并取得必要授权。

## 存储与对外传输

业务记录保存在后台设备的 SQLite 数据库及 Markdown 导出中，授权令牌保存在 Windows 凭据管理器。数据库和导出文件并不由应用自行加密；其访问保护由 Windows 账号权限、设备和备份设置共同决定。

登录和同步时，必要请求发送给 Google 或学校服务。用户启用邮件通知时，提醒内容发送给所配置的收件人；启用飞书通知或日历镜像时，相应提醒或日程内容发送给用户配置的飞书应用。默认影子模式不执行这些外部写入和投递。

可选远程看板提供独立登录及只读状态视图。用户启用 HTTPS 访问服务时，其网络流量由选择的访问服务承载。Agent 使用用户单独配置的凭证和权限访问本机业务接口；它是否进一步处理读取的数据，取决于用户使用的 Agent 环境及授权。

## 保留、停止和删除

数据保留在用户自己的设备和备份中，直到用户删除。断开账号后停止该账号后续同步，历史事项和邮件记录仍保留；断开账号不等同于删除全部历史资料，也不自动撤销 Google 服务器上的授权。

用户可以在 Google 账号的第三方应用连接页面撤销授权。要删除本地全部业务记录，应先停止后台，再删除程序数据目录、相关导出和备份；还应通过 Windows 凭据管理器删除本程序保存的账号授权条目。删除前应自行保存需要保留的资料。
