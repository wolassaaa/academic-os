# 项目声明｜第一次认真做项目，请多关照 (｡･ω･｡)ﾉ

大家好，这是我第一个正儿八经、想认真做下去的项目。

最开始只是想解决自己的一个小问题：邮件太多、作业分散、截止时间容易漏，能不能把这些东西收在一起，让学习和安排少一点手忙脚乱？于是就有了 Academic OS。

现在它还在一边使用、一边修改。代码、交互和文档肯定还有不成熟的地方，也会有我暂时没考虑周全的情况。第一次认真做项目，欢迎提意见，轻喷就好 (つ﹏⊂)

## 我想把它做成什么

不是再造一个什么都能干的“大系统”，而是一个尽量轻量、实用、能长期用下去的学业小工作台：看清作业与截止、整理邮件、自动分类，再把需要做的事安排好。

后续也想接入 Hermes，让它帮忙管理和反馈。目前 AI 分类只预留接口，默认关闭；不会因为写了“AI”就偷偷替你确认事项或修改日历。功能进度请以已合并代码和对应版本说明为准。

## 关于开发

这个项目使用了 AI 辅助开发和调试，也复用了已有的库与工具；相关来源与许可记录见 [第三方说明](../THIRD-PARTY-NOTICES.md)。我会继续补测试、修问题、整理文档，尽量把它从“自己能用”慢慢做成“别人也能放心试用”。

## 欢迎一起把它变好

欢迎提 Issue、反馈使用体验，也欢迎提交 PR。哪里不好用、哪里看不懂，都可以直接说；如果遇到 Bug，带上操作步骤和经过脱敏的报错信息，就很有帮助。

反馈时请不要上传真实邮件、账号凭据或个人数据库。感谢每一个愿意点进来看看、试用和提建议的人！慢慢来，但认真做。٩(ˊᗜˋ*)و
